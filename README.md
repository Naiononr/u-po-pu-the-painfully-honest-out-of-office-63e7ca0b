One brutally honest but still polite out-of-office auto-reply: the sender is away, the inbox is already 400 deep, and replies will come in the order each email survives their return.

## Run it

```sh
python3 -P -s main.py
```

The program writes the auto-reply to `/output/entry.txt` (1–200 characters, one sentence).
